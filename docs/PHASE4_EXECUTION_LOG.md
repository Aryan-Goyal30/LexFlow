## Key decisions

- **No approved judgment source** exists (`PHASE4_PLAN.md` Gate 2). The
  live collection therefore stays **empty**; everything is built and tested
  with **SYNTHETIC** fixtures (`server/tests/fixtures/judgments/synthetic`):
  invented, labelled, reserved `.invalid` web addresses, `(SYN)` citations.
  The importer refuses synthetic sources unless `--allow-synthetic` is given
  **and** the database name contains "test" or "e2e".
- **Provenance is mandatory:** every source records its terms of use (URL,
  date, who read them, what they permit); every judgment its source URL
  (https, no credentials). Real sources may not use reserved test domains.
- **Stable identity:** judgment id = uuid5(fixed namespace,
  `<source key>/<source's own id>`).
- **Duplicates:** same file (SHA-256) anywhere, same citation
  (case-insensitive), or the same id with changed content (replaced only
  with `--update`) are reported, never silently stored.
- **Atomicity:** each judgment is stored with its text and chunks in one
  transaction; extraction failures leave nothing behind.
- **Files are not kept**: the extracted text is stored; the source URL
  links to the original.
- **Access:** judgments are firm-wide reference material for **staff**
  (all staff roles); Client accounts never reach them; only the operator
  (command line) imports, indexes or removes.
