Service Description

Indiankanoon.org is a website that provides access to Indian legal "documents". It also provides a state of art "search functionality" over these documents. It also shows portions of a given document that contains a query that we call "document fragments".

IKanoon Application Programming Interface (API) refers to providing a programmatic way to access "search functionality", "documents" and "document fragments" as provided on the website IndianKanoon.org. The Application Programming Interface allows anyone to show these "documents", "search functionality" and "document fragments" on to their own website or product. It will be called "API Services" in short from now on.

Search features:
You can ask for any new search filter or ranking features to be incorporated in the API. Depending on the scope of work and the utility of the feature, IKanoon reserves the right to implement it or not. IKanoon will not be liable for any refusals.

Non-exclusive features:
IKanoon would neither provide you nor any other user of "API services" any exclusive search feature. Any new search filter or ranking feature ll be available to all users of IKanoon "API Services" as well as to the users of Indian Kanoon website. IKanoon will keep search filters and ranking features available through the API always updated on Indian Kanoon search tips page..

Authentication:
Every request to "API services" will be authenticated using public-private key crypto as explained in the documentation page. It is your responsibility to secure your private key. In case you lose the private key, it is your responsibility to update it on the profile page of "API Services". In case your key is mis-used, You will not be eligible for any refund.

Usage evidence:
IKanoon will provide you evidence of your usage of "API services" for last 30 days. You can view IP address, query and the signed certificate for that period.
